# SAMT — Life Command Tracker Version 2

This branch intentionally restores the richer standalone Version 2 application.

Open `index.html` directly in a modern browser. No account, server, or JSON file
is required: a fresh installation creates the Version 2 starter system. JSON is
only used for optional backup, restore, and Version 1 migration.

Version 2 includes Dashboard, Cycles, Actions, To-do, Projects, Reviews,
Analysis, History, Capacity, settings, and definition builders in one portable
HTML file. It uses the existing `life-command-progress-tracker-v2` browser
storage key and continues in memory if browser storage is unavailable.
